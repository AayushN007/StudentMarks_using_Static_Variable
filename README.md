```markdown
# Static Method Pass-Fail Checker

## Description
This Python program demonstrates the use of a **static method** inside a class.  
It takes a student's marks as input and checks whether the student has passed or failed based on the passing mark.

## Concept Used
- Class
- Static Method (`@staticmethod`)
- Conditional Statements (`if-else`)
- User Input

## Program Flow
1. Create a `student` class.
2. Define a static method `pass_fail()` to check marks.
3. Take marks from the user.
4. Compare marks with the passing mark (35).
5. Display the result as **Pass** or **Fail**.

## Example Output

```

Enter the marks: 78
Pass

```
```

Enter the marks: 20
Fail
